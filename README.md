# 儿童成长记录 App

这是一个面向两个孩子成长记录的 Android 原生应用，当前阶段聚焦 0 到 6 岁，优先覆盖幼儿园前后的高频记录场景。

## 当前已实现

- 双孩子档案切换
- 疫苗记录和下次接种提醒时间
- 生病、吃药和下次服药倒计时
- 睡觉和起床自动打点
- 出游记录
- 身高体重记录
- 双孩子成长曲线对比
- 园所记录：活动、反馈、请假、表扬等
- 提醒中心：统一展示疫苗、吃药和手动提醒
- 历史记录筛选页骨架
- 按年龄阶段给出记录建议

## 当前暂不开放

- 喂养记录页面

说明：喂养记录先不做页面，但数据结构会保留后续扩展空间。

## 产品方向

- 先服务自用，优先把记录做顺手
- 少打字，多用当前时间和结构化表单
- 先聚焦幼儿园前后的健康、作息、成长和园所记录
- 为后续上架应用商城预留扩展空间

## 本地环境说明

- 已补齐 Gradle Wrapper：`gradlew`、`gradlew.bat`
- Wrapper 默认使用本地压缩包：`.gradle-bootstrap/gradle-8.7-bin.zip`
- 当前工程已对齐 `compileSdk = 36`、`targetSdk = 36`
- 本机 `local.properties` 已指向 `D:\Android sdk`

## 运行方式

1. 用 Android Studio 打开项目根目录。
2. 等待 Gradle Sync 完成。
3. 连接真机或启动模拟器。
4. 点击运行 `app` 配置。

如果 Android Studio 首次同步仍提示缺依赖，优先检查 SDK、Gradle JDK 和网络代理设置。
